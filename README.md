# Sushiman 🍣

A modern, responsive website for Sushiman, showcasing the authentic taste of Japanese cuisine. Built with cutting-edge web technologies to deliver an immersive dining experience.

## 🌟 Live Preview

Check out the live version: [Sushiman Live](https://bank-modern-app-two-ivory.vercel.app/)

## ✨ Features

- **Hero Section**: Eye-catching introduction with stunning sushi imagery and Japanese characters.
- **Menu**: Explore our diverse sushi offerings.
- **Food Gallery**: Visual showcase of our culinary creations.
- **Services**: Learn about our dining services and ambiance.
- **About Us**: Discover the story behind Sushiman.
- **Responsive Design**: Optimized for all devices, from mobile to desktop.
- **Smooth Animations**: Powered by AOS (Animate On Scroll) for engaging user interactions.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure.
- **CSS3**: Custom styling with modular CSS files.
- **JavaScript**: Interactive elements and functionality.
- **Vite**: Fast build tool and development server.
- **AOS**: Library for scroll animations.

## 🚀 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/sushiman.git
   cd sushiman
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port shown in the terminal).

## 📖 Usage

- Navigate through the sections using the menu.
- Enjoy the smooth animations as you scroll.
- For production build, run `npm run build` and serve the `dist` folder.
